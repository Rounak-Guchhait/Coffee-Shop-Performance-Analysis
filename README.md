# Coffee Shop Performance Analysis

> **An end-to-end business intelligence project that analyzes coffee shop sales, customer behavior, and product performance using SQL and Power BI to generate actionable business insights.**

This project analyzes transactional data from a coffee shop business to uncover sales trends, customer purchasing patterns, and product performance. SQL was used to prepare and analyze the data, while Power BI was used to build an interactive dashboard that enables stakeholders to monitor key performance indicators and make informed business decisions.

# Project Overview 

Coffee shops generate large volumes of transactional data every day. Converting this data into meaningful insights helps businesses understand customer demand, optimize inventory, improve product offerings, and increase revenue.

This project demonstrates a complete analytics workflow by transforming raw sales data into an interactive executive dashboard.

---

# Business Objectives

* Analyze overall sales performance
* Identify top-performing coffee products
* Evaluate customer purchasing behavior
* Compare sales across different cities
* Discover seasonal and monthly sales trends
* Track business KPIs through an interactive dashboard
* Support data-driven business decisions

---

# Dataset Information

The project uses multiple relational datasets representing different aspects of the business.

| Dataset       | Description                     |
| ------------- | ------------------------------- |
| **Sales**     | Transaction-level sales records |
| **Customers** | Customer information            |
| **Products**  | Product catalog and pricing     |
| **Cities**    | Store location details          |

These datasets were joined using SQL to create a unified analytical model for reporting.

# SQL Analysis

SQL was used to answer key business questions, including:

* Total sales performance
* Revenue by city
